# Add Ironman Quest Prep

Ironman Quest Prep provides an item preparation checklist, manually selected gathering destinations and a quest-cape skill planner. It combines reusable requirements, compares them with bank/inventory ownership, and filters known quest-issued or locked supplies before constructing gathering guidance.

The skill view estimates training after fixed quest rewards while respecting skill and quest prerequisites. Its README describes the conservative rules for started quests, lamps, partial prerequisites and access checks.

The plugin uses the standard build, adds no production dependencies, performs no gameplay input automation and makes no network requests. Data derived from Quest Helper retains its BSD attribution.
